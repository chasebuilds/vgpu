effects

Live backgrounds that make a small site stand out.

Examples

Six fullscreen WebGPU shaders built on vgpu. Tap one to run it behind the page, then move your mouse or drag a finger to steer it.

<canvas id="hero" style="background:#1b1714"></canvas>
<script type="module">
  import { mountHero } from "https://chasebuilds.github.io/vgpu/chasebuilds/effects/hero.js";
  mountHero(document.getElementById("hero"), "embers");
</script>
Built by Chase Builds on vgpu (MIT, by Vercel Labs). Browsers without WebGPU see a still gradient.
